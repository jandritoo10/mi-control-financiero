Mi Control Financiero V2 — Instrucciones

1. Antes de actualizar, exporta una copia de seguridad desde Movimientos en V1.
2. Sube TODOS los archivos de esta carpeta al repositorio de GitHub, sustituyendo index.html y sw.js.
3. Abre el sitio y recarga si ves la versión antigua.
4. Crea un PIN de 6 dígitos; los datos V1 se migrarán al almacén cifrado local.
5. No olvides el PIN: no hay recuperación automática.
6. La copia JSON exportada desde la app NO está cifrada. Guárdala protegida.
7. El PIN ofrece protección básica, no equivale a seguridad bancaria. No hay biometría en V2.
8. El contenido del repositorio GitHub Pages es público: nunca subas copias de datos o PIN al repositorio.
